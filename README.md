# fruit classifier using supervised learning

A simple machine learning project demonstrating the core concept of supervised learning using Python and scikit-learn.

# overview

Just like showing flashcards to a child, this program teaches a decision tree model to tell the difference between apples and oranges based on two simple clues:
- weight in grams
- skin texture: smooth or bumpy

Once trained on labeled examples, the model correctly predicts what a mystery fruit is based on its features.
